# Contributing

Before changing source, read `AGENTS.md`, `GITHUB_RULES.md`, `.agent-standard/profile.json` and `.agent-standard/project-policy.md` at the exact target branch/HEAD. Preserve pinned portable-file parity and the project-specific restrictions.

Keep changes focused, review affected consumers and security boundaries, and distinguish source inspection from PC-local testing. Never dispatch cloud CI as a local test substitute or silently create branches, force-push, merge, deploy, release, or change other repositories.

For material commits, use the canonical continuity fields. The project's active development state lives in `docs/operations/current-state.md`, not in duplicate trackers.
